Este é um sistema de testes independente. Não é um sistema oficial da polícia e não opera com policiais.

Viagens, pessoas, diárias, assinaturas e documentos que aparecem aqui são fictícios e servem só para ensaiar os fluxos.

- Nenhum documento daqui tem valor oficial.
- Mensagens pelo WhatsApp do piloto só vão para testadores autorizados, com opt-in.
- Em caso de dúvida, fale com a equipe responsável pelo piloto.
